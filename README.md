# SNS・Webメディア・デジタル広報ポートフォリオ

佐々木ひろこのSNS運用、Webメディア、企業広報、Webサイト改善に関する独立ポートフォリオサイトです。

## 構成

- `index.html` — 1ページ構成の本体
- `assets/css/style.css` — レイアウト、配色、レスポンシブ対応
- `assets/js/main.js` — モバイルナビゲーション、表示演出、問い合わせフォーム
- `assets/icons/favicon.svg` — オリジナルのファビコン

## ローカル確認

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173/` を開いて確認します。

## 公開前の確認事項

- 公開前に問い合わせフォームのテスト送信を行う

## 公開URL

https://sasahiro-web.github.io/sns-web-portfolio/

## 制作上の方針

- 既存の総合ポートフォリオの配色、タイポグラフィ、余白、セクション構成を踏襲
- 他社の画像、ロゴ、公開ページのスクリーンショットを転載しない
- 指示書で確認された実績、担当範囲、公開URLのみを掲載
- 静的HTML/CSS/JavaScriptのみで構成
